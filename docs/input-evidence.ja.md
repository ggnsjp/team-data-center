# 入力の根拠：公表値との比較

モデルの入力のうち「仮定」としているものについて、公表されている値の範囲と、モデルの値がその中のどこにあるか、値を範囲の端まで動かすと結果がどれだけ動くかをまとめます。出典は 2026-11-26 に原資料を開いて確認しました。すべての値の一覧は [data-sources.md](data-sources.md)（英語）にあります。

このページは `src/dcopt/common/evidence.py` から作っています（`uv run python -m dcopt.common.evidence --write`）。[English](input-evidence.md)

## 結果をいちばん動かすもの（テーマ1）

1. **仮定の施設が結果の大半を支えている。** 公表中の計画（純便益 年93.8百万円）が届ける熱の49 %は、仮定の養殖施設と道路融雪の2か所向け。仮定の施設をすべて外して計画し直すと、純便益は年11.4百万円（13か所、6.0 km）。養殖と融雪は22〜25 ℃で足り、排熱をヒートポンプなしで使える。既存の建物は45〜60 ℃が必要で、1件ごとにヒートポンプが要る。
2. **需要の大きさがその次に効く。** すべての年間需要を0.7倍にすると28.4〜51.5、1.3倍で144.8。建物ごとの需要は床面積を使わない仮定で、公表されている原単位とは桁が合う程度の確認にとどまる。
3. **費用は2019年の価格である。** 導管費を2025年度の物価（1.22倍）に直すと72.7〜76.6。割引率4 %で78.3〜79.0、導管の寿命40年で108.4。
4. **置き換える灯油の量と価格。** 灯油1 Lの熱が7.6〜8.7 kWhの範囲で115.0〜80.7、低いほうの灯油価格を135円/Lにすると112.2。電気代30〜34円/kWhで87.4〜82.4。
5. **排熱の量と熱損失の影響は小さい。** 排熱は余っているので、回収率0.33で84.3、データセンターの電力を半分にして80.4、熱損失を2 %から3.7〜4.5 %にして92.0。

数値は `experiments/input_sensitivity/run.py` と `experiments/heat_loss_check/run.py` によります。入力を1つずつ動かした結果で、「a〜b」は、導管をそのままにした場合と計画し直した場合の幅です。
